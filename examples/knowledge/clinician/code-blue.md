# Code Blue (SAMPLE — fake values for development only)

## How to activate
Dial extension 1111 from any hospital phone and say "Code Blue" with the floor and room number.
Start CPR immediately. Do not wait for the team to arrive.

## Team response time
The Code Blue team must reach any in-patient area within 3 minutes of activation.
